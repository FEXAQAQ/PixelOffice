這裡的四段 GIF 皆錄自 PixelOffice 實際運行的網頁，呈現新版工作區介面與互動水族箱，沒有使用概念圖或生成式影像。

| aquarium.gif | 點開魚缸、投下飼料，展示三隻魚、兩隻蝦與各自的飽足感，再回到辦公室 |

## 錄製條件

- 2026-09-17，以本機 Node.js 服務、Playwright 與 Microsoft Edge 無頭瀏覽器錄製。
- Jira、Claude 與 Codex 均使用 `mock`；任務與設定使用獨立展示目錄。
- 畫面中的工單來自內建模擬資料，未執行真實 AI 開發、測試、提交或推送。
- 原始視窗 1440 × 1000；GIF 縮為 1008 × 700，每段使用共用 192 色調色盤、每格 180 ms 並循環播放。錄製取樣與 GIF 播放速度不保證逐毫秒一致。
- 每段使用新的瀏覽器工作階段；水族箱從預設飼養狀態開始，未修改魚蝦的飽足感。GIF 展示即時餵食互動，不展示跨日消耗或死亡過程。
- 錄影環境無法直接載入 CDN，故將專案原本引用的 Vue 與 Tailwind 腳本下載至暫存目錄，由瀏覽器請求攔截器提供原始腳本；未修改應用程式碼。

## 更新素材

1. 使用獨立連接埠，將 `PIXEL_OFFICE_MODE` 設為 `mock`。
2. 用 `TASK_DIR`、`AI_CONFIG`、`RUNTIME_CONFIG`、`PROJECTS_CONFIG`、`ENGINEERS_CONFIG` 指向獨立展示目錄內的任務資料夾與設定檔，以免混入日常任務、執行模式與專案路徑；設定 `OPEN_BROWSER=0`。
3. 每段以新的瀏覽器工作階段開啟頁面，等候連線與角色素材載入，設定森林、早晨。重錄接單片段前，使用空白的展示任務目錄，確保模擬工單尚未接取。
4. 依上表操作並錄製；保留應用程式的 Mock 標示，避免包含私人資訊。
5. 縮放與轉換後，確認動畫首、中、尾影格、文字可讀性及循環播放，再覆蓋同名 GIF。

人物與場景素材沿用專案既有資產。錄製畫面不變更原始素材授權；人物素材來源說明請見[使用手冊](../USER_GUIDE.md#人物穿著)。
